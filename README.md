# 能碳管理平台

基于《三期形态》的纯前端可交互原型，独立于主工程 `frontend/`，不接真实后端。

演示园区 Mock 为虚构的「绿港智造产业园」。

## 技术栈

- Vite + React 19 + TypeScript
- Ant Design 6
- ECharts（echarts-for-react）
- React Router 7

## 启动

```bash
cd frontend_demo
npm install
npm run dev
```

浏览器打开终端提示的地址（默认 http://localhost:8088 ）。

### 局域网访问（--host）

```bash
# 推荐：专用脚本
npm run dev:host

# 或把参数传给 vite（注意中间的 --）
npm run dev -- --host
```

启动成功后会同时出现：

- `Local:   http://localhost:8088/`
- `Network: http://192.168.x.x:8088/` ← 手机/同事用这个

端口被占用时，先查再结束进程（PowerShell）：

```powershell
netstat -ano | findstr :8088
taskkill /PID <上面最后一列PID> /F
```

## 演示园区 Mock

虚构园区：**绿港智造产业园**（苏州相城，约 1.2 km²）

- 3 个片区：东区制造 / 西区科创 / 公共配套
- 24 家企业（含 6 家重点用能单位）
- 约 40 栋建筑、96 块计量点、63 台设备
- 光伏约 8 MW、储能 2 MWh、充电桩 40 枪
- 告警 / 工单 / 碳核算 / 节能项目 / 填报任务等完整样例数据

数据位于 `src/mock/`。可变业务状态在内存 Context 中维护，**刷新页面会恢复初始 seed**。

## 功能菜单

对齐《三期形态》第十五章：综合驾驶舱、基础档案、能源管理、碳排放、新能源、设备运维、节能降碳、企业服务、数据中心、报表中心、系统管理。

## 重点可演示闭环（状态会真实变更）

1. **驾驶舱下钻**：园区总览企业排名 → 点击企业名 → 企业档案抽屉（`?id=`）
2. **能源一张图**：点击地图点位查看企业/设施卡片
3. **告警转工单**：实时监测「创建告警/标记异常」写入告警中心 → 转工单 → 工单派工/处理/完成
4. **碳核算任务流**：组织碳核算「新建任务 → 执行核算（两次推进）→ 审核通过」；碳预算「情景推演」会缩放 KPI/图表
5. **企业门户协同**：填报任务增删改查；表单可填汇总字段 + 活动数据明细行增删改；存草稿/提交后审核；整改任务增删改查与措施填写；工作台待办随状态变化
6. **导出**：档案 / 能耗统计 / 光伏 / 报表等导出为可打开的 CSV 文件
7. **接口同步**：系统管理 → 接口管理，同步/刷新会更新最近同步时间与状态
8. **表格 CRUD**：业务列表页普遍支持新建 / 编辑 / 删除（内存态，刷新恢复）；微网等纯图表页除外

顶部可切换片区与日/月/年统计周期。
